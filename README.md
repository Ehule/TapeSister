# TapeSister

TapeSister is a standalone sample-instrument project. Its design and implementation will be developed independently from FT2 Tapehead Edition.

- `main` is reserved for the newly designed instrument.
- `archive/prototype-v1` preserves the earlier prototype as historical raw material.
- Prototype code is not promoted to `main` by default.
- FT2 Tapehead Edition remains a separate project and must not be modified by TapeSister work.

The first design checkpoint will be defined collaboratively before implementation begins.
