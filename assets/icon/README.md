# TapeSister application icon

The icon is derived from the project's `tapesister_splash.png` artwork. The square
master removes the title area and retains the central character, waveform, and `S`
medallion so the identity remains legible at desktop-icon sizes.

- `tapesister-icon-master.png` is the high-resolution source.
- `png/` contains the standard raster sizes.
- `tapesister.ico` contains 16, 24, 32, 48, 64, 128, and 256 pixel images for
  the Windows executable resource.
